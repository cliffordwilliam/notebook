# Notebook

A browser-based rich text note taking app. The only dependency is Docker.

## Running

```bash
./scripts/build.sh
```

Builds the app inside Docker via `compose.yaml`, serves it on `http://localhost:8080`, and opens your browser. Press Ctrl+C to stop — the container and locally built image are removed automatically.

## Features

- Bold, headings (H2–H3), bullet and numbered lists, blockquotes, code blocks
- Language selector dropdown in the toolbar when a code block is active (C, C++, JavaScript, TypeScript, Python, Bash, CSS, HTML, JSON, SQL)
- Syntax highlighting in the note view (Prism.js, odin theme) with line numbers and a copy button on every code block
- Sticky toolbar — stays visible when writing long notes
- Table of contents in the note view — built from H2 headings, active heading tracks scroll position
- Toast notifications on create, save, and delete; error toasts for unexpected failures
- Skeleton loading on the note list, note view, and note edit screens
- Full-text search across title and content on the notes list
- Pagination (10 notes per page)

## Database setup

A NeonDB (or any PostgreSQL) connection string is required. The app talks to the database directly from the browser using the `@neondatabase/serverless` HTTP driver.

### Getting a connection string

Recommended provider: [NeonDB](https://neon.tech) — free tier, serverless Postgres, works directly from the browser without a backend.

1. Create a project (Postgres 17, pick the region closest to you)
2. Copy the **direct** connection string (not the pooled one):
   ```
   postgresql://user:password@host/dbname?sslmode=require
   ```
3. Put it in `.env` (copy `.env.example` as a starting point):
   ```
   DATABASE_URL="postgresql://user:password@host/dbname?sslmode=require"
   ```

### Provisioning the schema

Run once. Reads `DATABASE_URL` from `.env` automatically if no argument is given.

```bash
./scripts/db-setup.sh
# or explicitly:
./scripts/db-setup.sh 'postgresql://user:password@host/dbname?sslmode=require'
```

This creates:

```sql
CREATE TABLE IF NOT EXISTS notes (
  id          UUID        PRIMARY KEY DEFAULT gen_random_uuid(),
  title       TEXT        NOT NULL,
  content     TEXT        NOT NULL DEFAULT '',
  created_at  TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at  TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
```

### Connecting the app

Open `http://localhost:8080`, paste your connection string into the login screen, and click Connect. The string is stored in `localStorage` so you only enter it once per browser.

To disconnect or switch databases, click Disconnect on the notes list.

## What the app expects from the database

| JS field | DB column | Type | Notes |
|---|---|---|---|
| `id` | `id` | UUID | generated by `gen_random_uuid()` |
| `title` | `title` | TEXT | |
| `content` | `content` | TEXT | stores TipTap HTML output |
| `createdAt` | `created_at` | TIMESTAMPTZ | aliased in queries |
| `updatedAt` | `updated_at` | TIMESTAMPTZ | aliased in queries |

## Error handling

- **Auth failure** — redirects to the login screen and clears stored credentials
- **Schema mismatch** — shows a blocking error screen, credentials are preserved so you can fix the schema and retry without re-entering them

## Project structure

```
scripts/
  build.sh        — build and serve (the only command you need day-to-day)
  db-setup.sh     — create the notes table; reads .env if no argument given
src/
  lib/db.js       — all database operations (NeonDB HTTP via @neondatabase/serverless)
  lib/errors.js   — AuthError and SchemaError
  stores/         — credentials (localStorage), router, toasts
  pages/          — Login, NoteList, NoteCreate, NoteEdit, NoteView, ErrorPage
  components/     — Editor (TipTap), Toast
compose.yaml      — provisions the nginx container, exposes :8080
Dockerfile        — two-stage build: bun build → nginx image
.env              — your connection string (git-ignored)
.env.example      — template for the above
```
